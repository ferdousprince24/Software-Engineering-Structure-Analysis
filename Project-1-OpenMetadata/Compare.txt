“Our study compares human-written code with LLM-reconstructed code from two different projects: OpenMetadata and Apache Fineract. Both investigate whether LLMs can preserve the original software architecture and design patterns. The OpenMetadata project mainly shows how LLM reconstruction can lose abstractions and design patterns, while the Fineract project additionally studies how better prompting and explicit architectural constraints can improve preservation. So, our overall finding is that LLMs can reproduce functionality quite well, but architectural fidelity depends strongly on the quality of prompts and the architectural information provided to the model.”
